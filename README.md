# Student Management System

A simple **Student Management System** built using **Python Django**.

## 🛠️ Technologies

* Python
* Django
* PostgreSQL
* HTML
* CSS
* JavaScript

## ✨ Features

* Add Students
* View Students
* Edit Students
* Delete Students
* Manage Courses
* User Login & Logout

## 📁 Project Structure

```text
Student_Management_System/
├── config/
├── students/
├── courses/
├── manage.py
└── README.md
```

## ▶️ Run the Project

Clone the repository:

```bash
git clone https://github.com/your-username/Student_Management_System.git
```

Go to the project folder:

```bash
cd Student_Management_System
```

Activate virtual environment:

```bash
.venv\Scripts\Activate.ps1
```

Run migrations:

```bash
python manage.py migrate
```

Start the server:

```bash
python manage.py runserver
```

Open:

```text
http://127.0.0.1:8000/
```
